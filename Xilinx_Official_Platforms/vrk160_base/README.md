# Vitis Base Platform for the VRK160 Board 

***Version: 2026.1***

The VRK160 base platform provides a ready-to-use Vitis environment for application and accelerator development on the VRK160 evaluation kit. It includes pre-configured PS interfaces (UART, GEM, USB, SDIO) and integrates platform resources such as 16 GB LPDDR5X memory, multiple kernel clocks, AXI interfaces, interrupts, and AI Engine support. The platform follows the AMD Embedded Development Framework (EDF) with pre-built EDF images for rapid on-board bring-up. It is designed to accelerate compute-intensive and signal-processing applications while offering seamless integration with Vitis development flows.

For any hardware customization on the platform, please follow the custom platform tutorial in the [Vitis Tutorials](https://github.com/Xilinx/Vitis-Tutorials) repository.

### Hardware Configurations
The PS side hardware configurations are sourced from [Versal Embedded Common Platform - NO PL](https://github.com/Xilinx/XilinxCEDStore/tree/2026.1/ced/Xilinx/IPI/edf_base/1.0) Vivado Customizable Example Design (CED). The platform hardware resources and PL-facing configurations are listed below:    

| Configuration                 | Values                                                | Details                             |
| ----------------------------- | ----------------------------------------------------- | ------------------------------------|
| LPDDR Size                    | 8GB                                                   |                                     |
| Clocks for Kernels            | 625 MHz, 312.5MHz, 156.25MHz, 78.125MHz, 100.00MHz    | Clocks are synchronous to each other|
| SP Tags supported             | LPDDR                                                 | All kernels share same LPDDR5X      |
| Interrupts                    | 32 interrupts are enabled from PL Kernel to PS        |                                     |
| AXI Interfaces for Kernel Control | 28 M_AXI_GP AXI interfaces are enabled            |                                     |
| AI Engine                     | Enabled                                               |                                     |

>Note: The 625MHz clock is generated by clock generator with MBUGCE driver, designed to deliver a high clock frequency with minimal clock skew for AIE-related designs. The derived clocks generated from 625MHz MBUFGC are 625MHz, 312.5MHz, 156.25MHz and 78.125MHz. For more details about platform clock settings, please refer to the [Adding Clocks and Resets](https://docs.amd.com/r/en-US/ug1701-vitis-accelerated-embedded/Adding-Hardware-Interfaces) in UG1701.

>Note: This platform is based on CED platform, to get the tcl commands equavalent to platform, please refer to hw/xsa_scripts/reference_bd.tcl

### Software Configurations

VRK160 will follow the AMD EDF development flow. EDF will provide pre-built image for VRK160 board. For more details on the AMD EDF and software configurations, please refer to [AMD EDF](https://xilinx-wiki.atlassian.net/wiki/spaces/A/pages/3250585601/AMD+Embedded+Development+Framework+EDF) Wiki page.
